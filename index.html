Welcome

Every school keeps records: who is enrolled, who came to class today, who has paid fees and how each student did in exams. For years this was done in paper registers. Today most schools use a School Management System (SMS), software that keeps all these records in one place. In this module you will learn how an SMS works, how its data is organised, and how to keep that data safe.

Who this module is for

Grade 11 Computer Science students. You should be able to use a computer and a spreadsheet. No database experience is needed.

Length: two weeks

What you will be able to do

  1. Explain what an SMS is and name its main modules.
  2. Identify the data a school stores and organise it into tables.
  3. Use primary keys and foreign keys to link tables.
  4. Decide who should see which data, and explain why.
